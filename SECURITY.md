# Reporting security issues

Do not file a public issue for a suspected vulnerability. Email the
repository owner instead, with:

1. What you found and which commit or version it affects.
2. Steps to reproduce, ideally as a script.
3. What you think the impact is.

You will get an acknowledgment within 5 business days and a fix plan once
the issue is confirmed. Public disclosure waits until a patched release
exists.
